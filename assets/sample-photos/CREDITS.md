# Sample photos

**These images are not covered by the project's MPL 2.0 license.** Each keeps its own license, listed below. The files are downscaled copies (at most 1280 px wide); no other changes were made.

The "What it is" column records only what the source page states (title and description), so scan results can be checked against it.
